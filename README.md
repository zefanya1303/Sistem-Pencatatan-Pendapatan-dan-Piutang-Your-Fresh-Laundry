# Sistem-Pencatatan-Pendapatan-dan-Piutang-Your-Fresh-Laundry
Sistem informasi berbasis web untuk membantu pengelolaan usaha laundry melalui pencatatan data pelanggan, layanan cucian, transaksi, pembayaran, dan laporan pendapatan. Aplikasi ini menggunakan Supabase sebagai basis data untuk menyimpan dan mengelola informasi secara terstruktur.
